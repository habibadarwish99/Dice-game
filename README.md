# Dice Game

A Flutter app that rolls two dice and displays their total.

## How to run

1. Install Flutter.
2. Run `flutter pub get`.
3. Run `flutter run`.

## Rules

A total of 10 or more shows the happy image and "You Win".
A total below 10 shows the sad image and "You Lose".

Press Reset to return both dice to 1 and the total to 2.
